Installing the DAFS Teaching App

Running .py files

Author

Janpieter van der Pol

The DAFS Teaching App is a small program that runs on your own laptop and opens in your web browser. It walks you through the course’s Python lessons: you read a short explanation, write some code, press Run, and get feedback straight away.

To use it, you need to do three things only once:

  1. Install Python (the programming language the app is written in).
  2. Open a terminal (a window where you type commands).
  3. Type one command that downloads and installs the app.

After that, starting the app is a single command. This page walks you through every step. Choose your operating system in the tabs below; the choice carries over to all the other tabs on this page.

TipSet aside 15–20 minutes

Make sure you have a stable internet connection. Most of the time is spent waiting for downloads. You only have to do this once.

1 Install Python

  • Windows
  • macOS
  1. Go to python.org/downloads and click the big yellow Download button. The site detects that you’re on Windows and gives you the Python install manager.
  2. Open the file you downloaded (usually in your Downloads folder) and click Install.
  3. When it’s done, you can close the installer.
NoteAlternative: Microsoft Store

You can also open the Microsoft Store, search for Python Install Manager and click Install. This gives you exactly the same thing.

WarningDid you get a file called python-3.x.x-amd64.exe?

That is the old-style installer (you get it if you clicked a specific version further down the downloads page). It works too, but on its very first screen you must tick the box “Add python.exe to PATH” at the bottom before clicking Install Now. If you forget, Windows won’t find Python. Already installed without ticking it? Run the installer again, choose Modify → Next, tick Add Python to environment variables, and click Install. Or simply use py instead of python in every command on this page.

  1. Go to python.org/downloads and click the big yellow Download Python 3.x.x button. The site detects that you’re on a Mac and gives you a .pkg file.
  2. Open the downloaded file (usually in your Downloads folder) and click Continue / Agree / Install through the steps. Enter your Mac password when it asks.
  3. When it’s finished, a Finder window with a Python folder may open. You can close it.
WarningYour Mac might already “have” Python

Some Macs come with an old version of Python, or offer to install one as part of Apple’s developer tools. That one is too old for the app. Please install Python from python.org as described above, even if you think you already have it.

2 Open a terminal

The terminal is a window where you type commands instead of clicking. It looks intimidating, but you only need to copy and paste a few lines.

  • Windows
  • macOS

Click the Start button, type Terminal (on Windows 10: PowerShell), and press Enter.

A window opens with a line ending in >, for example PS C:\Users\yourname>. That is the prompt: you type your command after it.

Press Cmd + Space, type Terminal, and press Enter.

A window opens with a line ending in % or $. That is the prompt: you type your command after it.

TipHow to paste into the terminal

Every code block on this page has a copy button in its top-right corner. Click it, then click inside the terminal and paste:

  • Windows: Ctrl + V (or right-click)
  • macOS: Cmd + V

Then press Enter to run the command.

ImportantOpen a new terminal after installing Python

If you already had a terminal open while installing Python, close it and open a new one. An old terminal doesn’t know Python has been installed.

3 Check that Python works

Paste this into the terminal and press Enter:

  • Windows
  • macOS
python --version

The first time you do this, Windows may need a minute to finish setting up Python. If it asks you a question (for example whether to add something to your PATH, or to install a Python runtime), type y and press Enter.

python3 --version

Note the 3 in python3. On a Mac you always type python3, not python.

You should see something like Python 3.13.5. Any version that starts with 3.10 or higher is fine (3.10, 3.11, 3.12, 3.13, 3.14, …).

If you see an error, or a version lower than 3.10, look in the Troubleshooting section at the bottom of this page.

4 Install the app

Paste this command into the terminal and press Enter:

  • Windows
  • macOS
python -m pip install https://github.com/JPvdP/dafs-teach/archive/refs/heads/main.zip
python3 -m pip install https://github.com/JPvdP/dafs-teach/archive/refs/heads/main.zip

This downloads the app and everything it needs (Streamlit, pandas, NumPy and matplotlib). You’ll see a lot of text scrolling past. That’s normal. It can take a few minutes the first time.

It’s done when the prompt comes back and one of the last lines says something like:

Successfully installed ... dafs-teach-0.1.0 ...
NoteYellow “WARNING” lines are fine

You may see yellow or orange lines starting with WARNING, for example about a newer version of pip being available or a folder not being on PATH. You can ignore these. Only red lines starting with ERROR mean something went wrong.

5 Start the app

In the terminal, paste this and press Enter:

  • Windows
  • macOS
python -m dafs_teach
python3 -m dafs_teach

After a few seconds, your web browser opens a new tab with the app. If it doesn’t, look in the terminal for a line like Local URL: http://localhost:8501, and copy that address into your browser.

ImportantKeep the terminal open

The terminal window is what runs the app. If you close it, the app stops working. Leave it open (you can minimise it) for as long as you’re using the app.

The first time, the app asks for your name. Use your full name exactly as it appears on Brightspace, and always spell it the same way. Your completion codes are linked to this name.

Your progress is saved automatically on your own laptop, so you can stop the app and continue later where you left off.

6 Stop the app

When you’re done, stop the app in the terminal, not in the browser:

  1. Click inside the terminal window where the app is running.
  2. Press Ctrl + C. This is also Ctrl on a Mac, not Cmd.
  3. The terminal’s prompt comes back. The app has stopped. You can now close the browser tab and the terminal.

On Windows you may be asked Terminate batch job (Y/N)?. Type Y and press Enter.

WarningClosing the browser tab does not stop the app

If you only close the tab, the app keeps running in the terminal. If you then start it again in a second terminal, you end up with two copies running at the same time. Always stop it with Ctrl + C first. If you closed the tab by accident, just go to localhost:8501 in your browser to get back to it.

7 Next time: starting the app again

You don’t need to install anything again. Every time you want to use the app:

  1. Open a terminal (see Open a terminal).
  2. Run the start command:
  • Windows
  • macOS
python -m dafs_teach
python3 -m dafs_teach

8 Updating the app

New lessons are added during the course. When we announce an update, first stop the app if it’s running, then run:

  • Windows
  • macOS
python -m pip install --upgrade https://github.com/JPvdP/dafs-teach/archive/refs/heads/main.zip
python3 -m pip install --upgrade https://github.com/JPvdP/dafs-teach/archive/refs/heads/main.zip

Then start the app again. Your progress is kept.

9 Troubleshooting

  • Windows
  • macOS
python opens the Microsoft Store, or says “Python was not found”
Python isn’t installed yet, or Windows is using an old shortcut. Install Python as described in Install Python, then close the terminal and open a new one. If it still happens, open the Start menu, search for Manage app execution aliases, and make sure the entries for Python (default) are switched on (switch them off and on again if they already are).
python is not recognized, but py --version works
Use py instead of python in every command on this page, for example py -m pip install ... and py -m dafs_teach.

A permission error during installation (Access is denied, or Could not install packages due to an OSError) : This can happen on laptops managed by the university or your employer. Add --user to the install command:

python -m pip install --user https://github.com/JPvdP/dafs-teach/archive/refs/heads/main.zip
Windows Security or your antivirus asks about Python
Python is safe to allow. The app only runs on your own laptop.

python3 --version shows a version below 3.10, or a pop-up asks you to install “command line developer tools” : The Mac is using Apple’s built-in Python, not the one from python.org. Cancel the pop-up, install Python from python.org as described in Install Python, then close the terminal and open a new one and try again.

error: externally-managed-environment
You’re using a Python installed with Homebrew, which doesn’t allow this kind of installation. Install Python from python.org (see Install Python), open a new terminal, and try again. Do not use --break-system-packages.
A permission error during installation (Permission denied)
Add --user to the install command: 
python3 -m pip install --user https://github.com/JPvdP/dafs-teach/archive/refs/heads/main.zip
zsh: command not found: python
On a Mac the command is python3, with a 3.

Both systems:

No module named pip
Run python -m ensurepip --upgrade (Mac: python3 -m ensurepip --upgrade), then try the installation again.
No module named dafs_teach
The installation didn’t finish. Run the install command from Install the app again and check that it ends with Successfully installed.
The installation fails with a long red error mentioning “building wheel”, “Microsoft Visual C++”, or “metadata-generation-failed”
You probably have a brand-new version of Python for which some packages aren’t ready yet. Come and see us in the lab session, or install Python 3.13 instead. On Windows, run py install 3.13, then use py -V:3.13 instead of python in all commands. On a Mac, download 3.13 from the python.org Mac downloads page.
The app opens on localhost:8502 instead of localhost:8501, or says port 8501 is already in use
Another copy of the app is still running in a terminal you forgot about. Close all terminal windows, open a new one, and start the app again.
The browser says “Connection refused” or the page stops responding
Check that the terminal running the app is still open. If not, start the app again.
Still stuck?
Take a screenshot of the whole terminal window (including the error) and bring it to the lab session, or post it on the course forum on Brightspace.
