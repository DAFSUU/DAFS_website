Installing the DAFS Teaching App

From zero to a running app: no programming experience needed

Author

Janpieter van der Pol

The DAFS Teaching App is a small program that runs on your own laptop and opens in your web browser. It walks you through the course’s Python lessons: you read a short explanation, write some code, press Run, and get feedback straight away.

1 First: install Anaconda and create your course environment

The app runs on Python, and in this course we get Python from Anaconda, in a course environment called dafs. If you haven’t done so yet, do that first:

Important👉 Installing Python, Anaconda and Jupyter

Follow that page up to and including Create your course environment (all four steps), then come back here.

NoteDid you install Python from python.org or the Microsoft Store earlier?

An earlier version of this page asked you to do that. You don’t need to uninstall it, but from now on only use the Anaconda Prompt (Windows) or Terminal (macOS) with the dafs environment active, and install the app again as described below. Then everything runs in your course environment.

2 Open the Anaconda command window and activate dafs

  • Windows
  • macOS

Click Start, type Anaconda Prompt, and open it. The line starts with (base).

Don’t use Command Prompt, PowerShell or Terminal: those don’t know about Anaconda.

Press Cmd + Space, type Terminal, and press Enter. The line starts with (base).

No (base)? Quit Terminal completely (Cmd + Q) and open it again. See also the Anaconda troubleshooting.

Now activate your course environment:

conda activate dafs

The line now starts with (dafs). Do this every time before you install, start or update the app.

TipHow to paste a command

Every code block on this page has a copy button in its top-right corner. Click it, paste in the window (Windows: right-click or Ctrl + V; macOS: Cmd + V), and press Enter.

3 Install the app

With (dafs) at the start of the line, paste this command and press Enter. It’s the same on Windows and macOS:

python -m pip install https://github.com/JPvdP/dafs-teach/archive/refs/heads/main.zip

This downloads the app and anything it still needs. You’ll see a lot of text scrolling past. That’s normal. It can take a few minutes.

It’s done when the prompt comes back and one of the last lines says something like:

Successfully installed ... dafs-teach-0.1.0 ...
NoteYellow “WARNING” lines are fine

You may see lines starting with WARNING, for example about a newer version of pip or a folder not being on PATH. You can ignore these. Only lines starting with ERROR mean something went wrong.

4 Start the app

In the Anaconda Prompt (Windows) or Terminal (macOS), with (dafs) at the start of the line, paste this and press Enter:

python -m dafs_teach

After a few seconds, your web browser opens a new tab with the app. If it doesn’t, look in the window for a line like Local URL: http://localhost:8501, and copy that address into your browser.

ImportantKeep the window open

The Anaconda Prompt / Terminal window is what runs the app. If you close it, the app stops working. Leave it open (you can minimise it) for as long as you’re using the app.

The first time, the app asks for your name. Use your full name exactly as it appears on Brightspace, and always spell it the same way. Your completion codes are linked to this name.

Your progress is saved automatically on your own laptop, so you can stop the app and continue later where you left off.

5 Stop the app

When you’re done, stop the app in the Anaconda Prompt / Terminal, not in the browser:

  1. Click inside the window where the app is running.
  2. Press Ctrl + C. This is also Ctrl on a Mac, not Cmd.
  3. The prompt comes back. The app has stopped. You can now close the browser tab and the window.

On Windows you may be asked Terminate batch job (Y/N)?. Type Y and press Enter.

WarningClosing the browser tab does not stop the app

If you only close the tab, the app keeps running. If you then start it again in a second window, you end up with two copies running at the same time. Always stop it with Ctrl + C first. If you closed the tab by accident, just go to localhost:8501 in your browser to get back to it.

6 Next time: starting the app again

You don’t need to install anything again. Open the Anaconda Prompt (Windows) or Terminal (macOS) and run these two commands:

conda activate dafs
python -m dafs_teach

7 Updating the app

New lessons are added during the course. When we announce an update, first stop the app if it’s running, then run (with (dafs) at the start of the line; if not, first run conda activate dafs):

python -m pip install --upgrade https://github.com/JPvdP/dafs-teach/archive/refs/heads/main.zip

Then start the app again. Your progress is kept.

8 Troubleshooting

'python' is not recognized…, or the Microsoft Store opens (Windows)
You’re in Command Prompt, PowerShell or Terminal. Close it and open Anaconda Prompt instead.
No module named dafs_teach
The app isn’t installed in the Python you’re using. Usually you forgot to activate the environment: run conda activate dafs, check that the line starts with (dafs), and try again. If it still fails, run the install command from Install the app again (with (dafs) active).
EnvironmentNameNotFound: Could not find conda environment: dafs
You haven’t created the course environment yet. Follow Create your course environment first.
A permission error during installation (Access is denied, Permission denied, or Could not install packages due to an OSError)
Check that the line starts with (dafs): if it says (base), run conda activate dafs and try again. Don’t add --user to the command: that installs the app outside your course environment.
The app opens on localhost:8502 instead of localhost:8501, or says port 8501 is already in use
Another copy of the app is still running in a window you forgot about. Close all Anaconda Prompt / Terminal windows, open a new one, and start the app again.
The browser says “Connection refused” or the page stops responding
Check that the window running the app is still open. If not, start the app again.
Anything to do with installing Anaconda itself
See the Anaconda troubleshooting section.
Still stuck?
Take a screenshot of the whole window (including the error) and bring it to the lab session, or post it on the course forum on Brightspace.
