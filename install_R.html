Installing R and RStudio

A step-by-step setup guide for Windows and macOS: no programming experience needed

Author

Janpieter van der Pol

In this track you program in R. You install two programs:

  1. R, the programming language itself. It does the actual work, but you never open it directly.
  2. RStudio, the program you write and run your code in. It uses R in the background.

Think of R as the engine of a car and RStudio as the dashboard. You need both, and you install R first.

Choose your operating system in the tabs below; the choice carries over to all other tabs on this page.

TipSet aside 20–30 minutes

Use a stable internet connection, plug in your charger, and do this before the first lab session.

1 Before you start

  • Windows
  • macOS

Check your Windows version: click Start, type winver, and press Enter. You need Windows 10 or Windows 11.

Find out which Mac you have: click the Apple menu () in the top-left corner → About This Mac. Write down two things:

  • Chip or Processor: Apple M1/M2/M3/… (an Apple silicon Mac) or Intel.
  • macOS version: the name and number, for example macOS Sequoia 15.3.

You need macOS 13 (Ventura) or newer for RStudio. If your Mac is older, first update it via Apple menu → System Settings → General → Software Update. If that’s not possible, come and see us in the first lab session.

ImportantAlready have R or RStudio?

Check the version first (see Check that everything works). If R is version 4.2 or higher, you can skip to Install the tidyverse. If it’s older, install the new version over it as described below.

2 Install R

  • Windows
  • macOS
  1. Go to cran.r-project.org/bin/windows/base.
  2. Click the big link at the top, Download R-4.x.x for Windows.
  3. Open the downloaded file (R-4.x.x-win.exe, in your Downloads folder). If Windows asks “Do you want to allow this app to make changes to your device?”, click Yes.
  4. Choose your language, then click Next on every screen, keeping all the default options, and finally Finish.
NoteNo administrator rights?

On a laptop managed by the university or your employer, the installer may say you don’t have administrator rights and offer to install for you only. That’s fine: accept it and continue.

  1. Go to cran.r-project.org/bin/macosx.

  2. Download the right file for your Mac (see Before you start):

    Your Mac Download
    Apple silicon (M1, M2, …) with macOS 14 or newer the file ending in -arm64.pkg at the top of the page
    Apple silicon with macOS 13 R-4.5.3-arm64.pkg (the latest R that runs on macOS 13)
    Intel the file ending in -x86_64.pkg

  3. Open the downloaded .pkg file (in your Downloads folder).

  4. Click Continue / Agree / Install through the screens, keeping the default options. Enter your Mac password when asked.

  5. Click Close when it’s done.

WarningPick the right file

The arm64 version does not work on Intel Macs. The x86_64 version works on Apple silicon Macs, but much more slowly, and it causes problems with packages later. Check the table above.

3 Install RStudio

Only do this after R is installed.

  • Windows
  • macOS
  1. Go to posit.co/download/rstudio-desktop. You can skip step 1 on that page (“Install R”): you’ve just done that.
  2. Click Download RStudio Desktop for Windows, or pick the Windows installer (.exe) from the table further down.
  3. Open the downloaded file (RStudio-20xx.xx.x-xxx.exe) and click Next on every screen, keeping the default options, then Finish.
NoteWindows 10?

The download page may say “Windows 11”. The same installer works on Windows 10, so go ahead and use it.

  1. Go to posit.co/download/rstudio-desktop. You can skip step 1 on that page (“Install R”): you’ve just done that.
  2. Click Download RStudio Desktop for macOS, or pick the macOS file (.dmg) from the table further down. The same file works on Apple silicon and Intel Macs.
  3. Open the downloaded .dmg file. A window opens with the RStudio icon and an Applications folder.
  4. Drag the RStudio icon onto the Applications folder. This is the actual installation step: don’t skip it, and don’t start RStudio from this window.
  5. Close the window, and eject the RStudio disk in Finder’s sidebar (click the ⏏ symbol next to it).
NotemacOS 13 or 14?

The download page may say “macOS 15+”, but RStudio works on macOS 13 and newer. If the newest RStudio refuses to open, download an older version from Posit’s list of previous versions.

4 Open RStudio

  • Windows
  • macOS

Click Start, type RStudio, and open it.

Tip: right-click the RStudio icon in the taskbar and choose Pin to taskbar so you can find it easily next time.

Open your Applications folder and double-click RStudio. The first time, macOS may ask whether you’re sure you want to open it: click Open.

Tip: while RStudio is open, right-click its icon in the Dock and choose Options → Keep in Dock so you can find it easily next time.

ImportantAlways open RStudio, not R

After installing, you’ll also have a program called R (or R x64 4.x.x, or R.app). You don’t need to open that one. For this course, always open RStudio.

RStudio shows several panels. The one on the left (or bottom left) is the Console: this is where R runs your commands. You’ll see a > symbol there, which means R is waiting for you to type something.

5 Check that everything works

Look at the first lines of the Console. It says something like:

R version 4.6.2 (2026-xx-xx) -- "..."

Any version 4.2 or higher is fine. Now click in the Console, type the line below, and press Enter:

1 + 1

R should answer [1] 2. If it does, R and RStudio are working.

TipHow to paste a command

Every code block on this page has a copy button in its top-right corner. Click it, click in the RStudio Console, paste (Windows: Ctrl + V; macOS: Cmd + V) and press Enter.

6 Install the tidyverse

The tidyverse is a collection of R packages we use throughout the course (for reading data, making tables, plotting, …). Install it once by running this in the Console:

install.packages("tidyverse")

This takes a few minutes, and you’ll see a lot of text in red. Red text in R is not necessarily an error: R uses red for all its messages. Wait until the > prompt comes back.

TipQuestions R may ask you during the installation
  • “Would you like to use a personal library instead?” and then “Would you like to create a personal library … to install packages into?” Type yes both times and press Enter. This happens on laptops where you don’t have administrator rights.
  • “Do you want to install from sources the packages which need compilation?” Type no and press Enter.
  • “These packages have more recent versions available. Which would you like to update?” Type 3 (None) and press Enter.
  • On some computers, a window asks you to choose a CRAN mirror. Pick 0-Cloud (or any location near you) and click OK.

Then check that it works:

library(tidyverse)

You should see a short overview starting with something like ── Attaching core tidyverse packages ── and a list of package names with green ticks (✔). The “Conflicts” part below it is normal. If you see Error in library(tidyverse) : there is no package called 'tidyverse', run the install.packages() line again and read the Troubleshooting section.

7 Two recommended settings

These settings prevent confusing situations later. In RStudio, go to Tools → Global Options… → General (macOS: also via RStudio → Settings…) and set:

  • Restore .RData into workspace at startup: ❌ untick.
  • Save workspace to .RData on exit: choose Never.

Click OK.

NoteWhy?

Otherwise RStudio secretly reloads all the variables from your previous session. Code that seems to work may then fail on someone else’s computer (or on the exam), because it depends on something that is no longer in your script. With these settings, every RStudio session starts clean, and your script is the only thing that counts.

8 Make a project folder for this course

Keep all your course files in one place, using an RStudio Project. It makes sure R always looks for your data files in the right folder.

  1. In RStudio, click File → New Project… → New Directory → New Project.
  2. Directory name: type DAFS.
  3. Create project as a subdirectory of: click Browse… and pick a folder you can easily find, for example your Documents folder.
  4. Click Create Project. RStudio restarts inside the project.
  5. Put your scripts and the data files you download for the course in this DAFS folder.

Next time, open the project via File → Open Project… or the project menu in the top-right corner of RStudio (it shows DAFS while the project is open).

TipWhy a project?

With the project open, read_csv("data.csv") finds data.csv in your DAFS folder: you don’t need long paths like C:/Users/jdevries/Downloads/data.csv. Most “file not found” errors in this course come from data files that are still sitting in the Downloads folder.

Your setup is complete! Next step: install the R Teaching App.

9 Troubleshooting

  • Windows
  • macOS
RStudio says it can’t find R, or asks you to choose an R installation
R isn’t installed (yet). Install R first (see Install R), then restart RStudio. If RStudio asks you to choose a version, pick the newest 64-bit R.
“Access is denied” or “you don’t have permission” during installation
Accept the option to install for your own user only. If the installer doesn’t offer that, ask your IT department, or come to the lab session.
'lib = ...' is not writable when installing packages
Restart R (Session → Restart R), run install.packages() again, and answer yes when R asks about a personal library.
A warning that “Rtools is required to build R packages”
You can ignore it. We only install ready-made packages, which don’t need Rtools. If R asks whether to install from source, answer no.
“RStudio can’t be opened because Apple cannot check it for malicious software”
Open System Settings → Privacy & Security, scroll down, and click Open Anyway next to the message about RStudio.
RStudio doesn’t appear in Applications / it disappears after a restart
You opened RStudio from the download window instead of dragging it to Applications. Open the .dmg again and drag the icon onto the Applications folder (see Install RStudio).
“This package is incompatible with this version of macOS” or R crashes when starting
You probably downloaded the wrong R for your Mac. Check the table in Install R, download the right file, and install it.
RStudio says it can’t find R
Install R first (see Install R), then quit RStudio (Cmd + Q) and open it again.
A pop-up asks to install “command line developer tools”
Click Cancel. This happens if R tries to build a package from source. When R asks whether to install from source, answer no.

Both systems:

there is no package called '...'
The package isn’t installed yet. Run install.packages("...") with the package name, then library(...) again.
cannot open file '...': No such file or directory when reading data
The data file isn’t in your project folder. Move it into your DAFS folder (see Make a project folder), and make sure the DAFS project is open (top-right corner of RStudio).
The installation hangs, or fails with a download error
Check your internet connection, restart RStudio, and run the command again. On campus Wi-Fi with many students installing at once, it can help to try again from home.
Still stuck?
Take a screenshot of the whole RStudio window (including the error) and bring it to the lab session, or post it on the course forum on Brightspace.
