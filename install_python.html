Installing Python, Anaconda and Jupyter

A step-by-step setup guide for Windows and macOS: no programming experience needed

Author

Janpieter van der Pol

In this course you write Python code in Jupyter Notebooks. To get those on your laptop, you install one program: Anaconda. Anaconda contains:

  • Python, the programming language;
  • Jupyter Notebook, the program you write and run your code in (it opens in your web browser);
  • the packages we use in class (pandas, NumPy, matplotlib, …), already installed;
  • Anaconda Prompt (Windows) / the Terminal (macOS), a window to type the occasional command in.

This page takes you through the installation step by step. Choose your operating system in the tabs below; the choice carries over to all other tabs on this page.

TipSet aside 30 minutes

Anaconda is a big download (about 1 GB) and takes 10–20 minutes to install. Use a stable internet connection, plug in your charger, and do this before the first lab session.

1 Before you start: three rules

These three rules prevent almost every installation problem we’ve seen in previous years.

Important1. Install Python only via Anaconda

Do not install Python from the Microsoft Store or from python.org for this course. If you already have such a Python, you don’t need to remove it. Just follow this guide, and we’ll make sure you always use the Anaconda one.

Important2. Windows: do not tick “Add Anaconda to my PATH”

The installer offers this option. Leave it unticked. Instead of changing Windows settings, you’ll use the Anaconda Prompt, which always finds the right Python.

Important3. Install only one Anaconda

If you already have Anaconda from another course, don’t install it a second time. Skip to Check that everything works. If that check fails, uninstall the old Anaconda first (see Troubleshooting).

2 Download Anaconda

  • Windows
  • macOS
  1. Go to anaconda.com/download.
  2. Anaconda asks for your email address before you can download. Use your student email and follow the link you receive. Registration is free. (If you see a Skip registration link, you can use that instead.)
  3. Under Anaconda Distribution, download the Windows 64-bit graphical installer. The file is called something like Anaconda3-2026.07-1-Windows-x86_64.exe.
NoteDon’t pick “Miniconda”

The download page also offers Miniconda. That is a stripped-down version without Jupyter and the packages we need. Make sure you download Anaconda Distribution.

First, find out which kind of Mac you have: click the Apple menu () in the top-left corner → About This Mac.

  • If it says Chip: Apple M1/M2/M3/M4/…, you have an Apple silicon Mac (most Macs from 2021 onwards).
  • If it says Processor: … Intel …, you have an Intel Mac.

Apple silicon (M1, M2, …):

  1. Go to anaconda.com/download.
  2. Anaconda asks for your email address before you can download. Use your student email and follow the link you receive. Registration is free. (If you see a Skip registration link, you can use that instead.)
  3. Under Anaconda Distribution, download the 64-bit (Apple silicon) graphical installer. The file is called something like Anaconda3-2026.07-1-MacOSX-arm64.pkg.

Intel Mac: Anaconda no longer makes new versions for Intel Macs, so the download page won’t offer one. Download the last Intel version directly from this link instead (no registration needed). It works fine for this course:

Anaconda3-2025.06-1-MacOSX-x86_64.pkg

NoteDon’t pick “Miniconda”

The download page also offers Miniconda. That is a stripped-down version without Jupyter and the packages we need. Make sure you download Anaconda Distribution.

3 Install Anaconda

  • Windows
  • macOS

Open your Downloads folder and double-click the installer. Then go through the screens like this:

  1. Welcome: click Next.

  2. License Agreement: click I Agree.

  3. Select Installation Type: choose Just Me (recommended), then Next.

  4. Choose Install Location: look at the folder it suggests, for example C:\Users\jdevries\anaconda3.

    • If that path has no spaces and no special characters (like é, ë, ü, ø, &), keep it and click Next.
    • If your username has spaces or special characters (for example C:\Users\Jan de Vries\anaconda3 or C:\Users\Zoë\anaconda3), change the folder to C:\anaconda3 and click Next.

  5. Advanced Installation Options: set the boxes like this:

    Option Set to
    Create shortcuts ✅ ticked
    Add Anaconda3 to my PATH environment variable ❌ not ticked
    Register Anaconda3 as my default Python ✅ ticked
    Clear the package cache upon completion ✅ ticked

    Then click Install.

  6. Wait. This takes 10–20 minutes. The progress bar sometimes seems stuck on one file for a few minutes; that’s normal. Don’t close the window.

  7. Click Next until you see Finish. You can untick the boxes about tutorials and getting started, then click Finish.

WarningWindows Security / antivirus warnings

Windows may ask “Do you want to allow this app to make changes to your device?”. Click Yes. Anaconda is safe.

Open your Downloads folder and double-click the .pkg file. Then:

  1. Click Continue on the introduction screens.
  2. License: click Continue, then Agree.
  3. Installation Type / Destination: keep the suggested option and click Continue, then Install.
  4. Enter your Mac password when asked (the one you use to log in).
  5. Wait 5–15 minutes, then click Close. If macOS asks whether to move the installer to the Bin, you can say yes.

4 Open the Anaconda command window

Once in a while you’ll need to type a command (for example to start Jupyter, or to install an extra package). Always use the window below for this.

  • Windows
  • macOS

Click Start, type Anaconda Prompt, and open it.

A black window opens. The line starts with (base), for example:

(base) C:\Users\jdevries>

The (base) tells you that Anaconda’s Python is active.

ImportantUse Anaconda Prompt, not Command Prompt or PowerShell

Windows also has Command Prompt, PowerShell and Terminal. Those do not know about Anaconda (because we didn’t add it to the PATH, on purpose). If a command on this website says “python is not recognized” or opens the Microsoft Store, you’re in the wrong window. Close it and open Anaconda Prompt instead.

Press Cmd + Space, type Terminal, and press Enter.

The line should start with (base), for example:

(base) jan@MacBook-Air ~ %

The (base) tells you that Anaconda’s Python is active.

ImportantDon’t see (base)?

Close all Terminal windows (Cmd + Q quits Terminal completely) and open Terminal again. Terminal windows that were open during the installation don’t know about Anaconda yet. Still no (base)? See Troubleshooting.

TipHow to paste a command

Every code block on this page has a copy button in its top-right corner. Click it, then paste in the window (Windows: right-click or Ctrl + V; macOS: Cmd + V) and press Enter.

5 Check that everything works

In the Anaconda Prompt (Windows) or Terminal (macOS), paste this and press Enter:

python -c "import sys, pandas, numpy, matplotlib; print('Python', sys.version.split()[0]); print(sys.executable)"

You should see two lines like this:

  • Windows
  • macOS
Python 3.14.0
C:\Users\jdevries\anaconda3\python.exe
Python 3.14.0
/opt/anaconda3/bin/python

Check two things:

  • The version is 3.10 or higher. The exact number doesn’t matter.
  • The second line contains anaconda3. This proves you’re using Anaconda’s Python and not another one.

If you get an error instead, see Troubleshooting.

6 Start Jupyter Notebook

  1. Open the Anaconda Prompt (Windows) or Terminal (macOS), as in Open the Anaconda command window.

  2. Type this and press Enter:

    jupyter notebook

  3. After a few seconds, Jupyter opens in your web browser. It shows the files and folders in your home folder.

ImportantKeep the black/Terminal window open

That window is what runs Jupyter. If you close it, Jupyter stops working and you can’t save your notebook anymore. Minimise it, but keep it open while you work.

NotePrefer clicking? Use Anaconda Navigator

You can also open Anaconda Navigator (Windows: from the Start menu; macOS: from your Applications folder), and click Launch under Jupyter Notebook. The result is the same. If Navigator is slow or doesn’t open, use the jupyter notebook command above. It’s the more reliable route.

6.1 Make a folder for this course

Keep all your course files in one place. In Jupyter’s file view:

  1. Click New (top right) → New Folder.
  2. Select the new folder (tick the box in front of Untitled Folder), click Rename, and call it DAFS.
  3. Click the DAFS folder to open it. Put your notebooks and the data files you download for the course in this folder.
TipWhy this folder?

Your notebook looks for data files in the folder it is in. If the notebook and the data file are in the same folder, pd.read_csv("data.csv") just works. Most “file not found” errors in this course come from data files that are still sitting in the Downloads folder.

To get a downloaded file into this folder, use Jupyter’s Upload button (top right) while you’re in the DAFS folder.

6.2 Your first notebook

  1. Inside the DAFS folder, click New → Notebook. If it asks for a kernel, choose Python 3.

  2. Click in the first cell, type the line below, and press Shift + Enter to run it:

    print("Hello, I'm ready for DAFS!")

  3. If the text appears below the cell, your setup is complete!

  4. Save with Ctrl + S (macOS: Cmd + S). Rename the notebook by clicking its name (Untitled) at the top.

7 Stopping Jupyter

When you’re done:

  1. Save your notebook.
  2. In Jupyter, go to File → Shut Down (in older versions: click Quit in the file view).
  3. You can now close the browser tab and the Anaconda Prompt / Terminal.

If that doesn’t work, click inside the Anaconda Prompt / Terminal window and press Ctrl + C (also on a Mac: Ctrl, not Cmd). Press it twice if needed, or type y and Enter if it asks for confirmation.

8 Installing extra packages

Anaconda already has almost everything we use. If you do need to install an extra package, do it inside your notebook with %pip:

%pip install packagename

After installing, restart the kernel: Kernel → Restart Kernel.

TipWhy %pip and not pip or !pip?

%pip always installs the package into the exact Python your notebook is using. !pip or pip in another window can install it into a different Python on your computer, after which the notebook still says ModuleNotFoundError. That’s the classic “I installed it but it doesn’t work” problem.

9 Troubleshooting

  • Windows
  • macOS
'python' is not recognized…, 'jupyter' is not recognized…, or the Microsoft Store opens
You typed the command in Command Prompt, PowerShell or Terminal. Close that window, open Anaconda Prompt from the Start menu, and try again.
I can’t find “Anaconda Prompt” in the Start menu
The installation didn’t finish, or “Create shortcuts” was unticked. Run the installer again (see Install Anaconda).
The check shows a path without anaconda3 (for example with WindowsApps or Python314)
You’re not in the Anaconda Prompt. Open Anaconda Prompt and run the check again.
The installer says the path contains spaces or invalid characters
Change the install folder to C:\anaconda3 (see step 4 of Install Anaconda).
“Access is denied”, “Setup was unable to create the directory”, or “Error opening file for writing” during installation
Move the installer to your Downloads folder (not Favorites, not OneDrive), and run it from there. If your antivirus is blocking the install, turn it off temporarily during the installation, and turn it back on afterwards. On a laptop managed by your employer, you may need your IT department.
I ticked “Add Anaconda3 to my PATH” by accident
Uninstall Anaconda (Start → Settings → Apps → Anaconda3 → Uninstall) and install it again without ticking that box.
No (base) in Terminal, or zsh: command not found: conda / jupyter
First quit Terminal completely (Cmd + Q) and open it again. If it still doesn’t work, paste this command, press Enter, then quit and reopen Terminal: 
/opt/anaconda3/bin/conda init zsh
The check shows a path without anaconda3 (for example /usr/bin/python3 or /Library/Frameworks/... or /opt/homebrew/...)
Terminal is using a different Python. Do the conda init step above, quit Terminal, reopen it, and check that you see (base).
“The installer can’t be opened because it is from an unidentified developer”
Right-click (or Ctrl-click) the .pkg file, choose Open, and then Open again.
A pop-up asks to install “command line developer tools”
Click Cancel. You typed python3 (or git) in a Terminal that doesn’t know about Anaconda. Quit Terminal (Cmd + Q), reopen it, and make sure you see (base).

Both systems:

ModuleNotFoundError: No module named ... in a notebook
Install the package with %pip install ... inside the notebook, then Kernel → Restart Kernel (see Installing extra packages).
FileNotFoundError when reading a data file
The data file is not in the same folder as your notebook. Upload it into your DAFS folder (see Make a folder for this course).
Jupyter opens, but my notebook won’t save, or cells don’t run anymore
You probably closed the Anaconda Prompt / Terminal window. Start Jupyter again with jupyter notebook.
The download page looks different from what’s described here
Anaconda sometimes redesigns its website. You can always download the installer directly from repo.anaconda.com/archive (no registration). Pick the newest file ending in -Windows-x86_64.exe (Windows) or -MacOSX-arm64.pkg (Apple silicon Mac). Intel Macs: use the link in Download Anaconda.
My old Anaconda doesn’t work / I want to start over
Uninstall it first. Windows: Start → Settings → Apps → Anaconda3 → Uninstall. macOS: in Terminal, run the command below and type your Mac password when asked (you won’t see it as you type, that’s normal). Then quit Terminal. 
sudo rm -rf /opt/anaconda3 ~/anaconda3 ~/opt/anaconda3
Then install Anaconda again following this guide. Not comfortable doing this? Bring your laptop to the lab session and we’ll do it together.
Still stuck?
Take a screenshot of the whole window (including the error) and bring it to the lab session, or post it on the course forum on Brightspace.
